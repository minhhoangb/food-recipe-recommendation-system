# AI annotations: post-judging review only

Do not open any artifacts in this directory before independent human labels are
locked. This includes relevance CSVs, summaries, examples and metadata containing
label counts. Human judging instructions and assignment files are in
`reports/manual_eval/`.

The `dev/` directory contains a single AI annotation pass with its provenance.
These are AI suggestions, not judgments by Hoang, Hung or Hieu. Keep the original
human labels when comparing or adjudicating after locking them. Record any prior
exposure; relocating files cannot restore independence once suggestions were seen.
